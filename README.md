# 🚗 Car Repair Diary — твой персональный журнал обслуживания авто

> «Запиши ремонт — не забудь вовремя»

**Car Repair Diary** — это набор консольных приложений для учёта ремонтов и обслуживания вашего автомобиля.  
Храните историю с датами, пробегом, описанием и стоимостью — всегда под рукой.

## 🚀 Особенности
- 📝 Добавление записей: дата, пробег (км), описание, стоимость.
- 📋 Просмотр всех записей в удобной таблице.
- 🔍 Поиск по дате, пробегу или ключевому слову.
- 🗑️ Удаление записи по ID.
- 📊 Статистика: общая стоимость, средний пробег между ремонтами.
- 💾 Автосохранение в JSON-файл (`repairs.json`).
- 🎨 Цветной вывод в терминале и интерактивное меню.
- 📤 Экспорт в CSV (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости              | Команда запуска                         |
|------------|--------------------------|-----------------------------------------|
| Python     | стандартная библиотека   | `python car_diary.py`                   |
| Go         | стандартная библиотека   | `go run car_diary.go`                   |
| Ruby       | стандартная библиотека   | `ruby car_diary.rb`                     |
| Java       | стандартная библиотека   | `javac car_diary.java && java car_diary`|
| JavaScript | Node.js, никаких         | `node car_diary.js`                     |
| C#         | .NET (или mono)          | `dotnet run`                            |
| Rust       | `serde`, `serde_json`    | `cargo run`                             |
| PHP        | стандартная библиотека   | `php car_diary.php`                     |

> Все программы создают файл `repairs.json` в той же папке.
